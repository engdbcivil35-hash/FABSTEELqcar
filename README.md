# FAB STEEL AR QC — نسخه ۱۰ (اندروید بومی، Kotlin + ARCore)

چیدمان رابط کاربری مطابق `UI-reference.png` است.

## ساخت APK
1. Android Studio (نسخه Koala یا جدیدتر) را باز کنید: File ▸ Open ▸ پوشه‌ی `FabSteelARQC`.
2. اجازه دهید Gradle Sync انجام شود (اینترنت لازم است).
3. گوشی POCO را با USB وصل کنید و «USB debugging» را روشن کنید، سپس Run ▸ Run 'app'.
4. APK نهایی: Build ▸ Build Bundle(s)/APK(s) ▸ Build APK(s).
5. روی گوشی باید «Google Play Services for AR» نصب باشد؛ برنامه در اولین اجرا خودش درخواست نصب می‌دهد.

## طرز کار
- Tekla Upload IFC: خروجی IFC تکلا را انتخاب کنید.
- علامت + را روی نقطه‌ی مرجع قطعه بگذارید. نقطه‌ی مرجع گوشه‌ی مینیمم مدل است (پایین-چپ-جلو). با کشیدن انگشت یا دکمه‌های « » مدل را بچرخانید.
- Fix: مدل قفل می‌شود (دوباره بزنید: Unfix).
- دو دقت جدا: «دقت اجزا» (بال، جان، دستک، استیفنر، اتصالات) و «دقت سوراخ‌کاری». با لمس کارت‌ها تغییر می‌کنند.
- مغایرت: قطعه قرمز می‌شود، لوگوی بالا-راست چشمک می‌زند و بوق پیوسته می‌خورد.
- تم روشن/تاریک و صدا از «تنظیمات».

## ابزارهای نوار وسط-راست (الهام از فیلم مرجع)
- ✂ برش: لغزنده، مدل را روی محور X یا Y (بالا) یا Z می‌برد تا قطعه‌ی واقعی زیرش دیده شود (مثلاً مقایسه‌ی چشمی سوراخ‌ها). دکمه‌ی ⇄ جهت برش را برعکس می‌کند. لغزنده را روی ۱۰۰٪ ببرید تا برش خاموش شود.
- ◐ شفافیت: میزان پُری سطوح آبی مدل.
- 📏 متر: دو نقطه را روی سطح (کف، قطعه‌ی واقعی) لمس کنید؛ فاصله‌ی سه‌بعدی بر حسب mm نشان داده می‌شود. دقت آن در حد دقت ردیابی ARCore است (سانتی‌متر)، نه کولیس.
- برچسب Tracking در بالا-چپ: Perfect / Good / Poor.
- نوار «Step» فیلم مرجع اضافه نشد، چون پایین-وسط در طرح شما مال دکمه‌ی Fix است.

## محدودیت‌های مهم (صادقانه)
- مقایسه‌ی مدل با قطعه‌ی واقعی با نقشه‌ی عمق ARCore انجام می‌شود (فقط اگر گوشی از Depth API پشتیبانی کند). دقت این حسگر در فاصله‌ی ۱ تا ۲ متر در حد چند سانتی‌متر است، نه ۳ تا ۵ میلی‌متر.
  به همین دلیل برنامه «حد نویز حسگر» (پیش‌فرض ۱٪ فاصله) دارد و تلرانس مؤثر را بزرگ‌تر از مقدار تنظیم‌شده می‌گیرد. در این حالت در پنل هشدار پیام می‌دهد.
- بنابراین نسخه‌ی فعلی مغایرت‌های درشت را تشخیص می‌دهد (قطعه‌ی جا افتاده، اشتباه در طول یا موقعیت چندین سانتی‌متری). اندازه‌گیری میلی‌متری سوراخ‌ها و ضخامت‌ها با دوربین گوشی ممکن نیست؛ برای آن به لیزر یا اسکنر نیاز است.
- هیچ‌چیز روی گوشی واقعی با IFC واقعی تکلا آزمایش نشده است. پارسر IFC از این هندسه‌ها پشتیبانی می‌کند: Extruded (مستطیل، I، L، دایره، چندضلعی)، Faceted Brep، Triangulated Face Set، Mapped Item. IfcPolygonalFaceSet و پروفیل‌های U/T/C پشتیبانی نمی‌شوند.
- آیکن‌ها آیکن‌های سیستم اندروید هستند و می‌توان آن‌ها را با آیکن اختصاصی جایگزین کرد.
